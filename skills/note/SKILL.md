# 笔记 Skill

## 写入规则（通用）

- 直接写 `.md` 文件到 `/mnt/d/Administrator/Desktop/个人文件/ZoteroNotes/`
- 文件名与正文第一行一致
- 公式用标准 LaTeX 语法
- 中文为主，术语保留英文

---

## 类型 A：论文笔记

**触发**：讨论内容围绕某篇具体论文的概念/方法/模块时。

**YAML 头**：必须包含 `parent` 和 `zoteroKey`，笔记会挂载到对应 Zotero 条目下。

```markdown
---
parent: '完整论文标题'
zoteroKey: 'Zotero物品KEY'
tags: [AI总结]
model: xx模型
---

概念英文名 中文说明

> 由 XX模型 于 YYYY-MM-DD 生成

概念名称 是 [作者] 在 [论文] 中提出的 [一句话定位]，核心思路是 [关键思想]。

## 论文中的介绍

论文中的介绍如下：...（总结原论文内容，保留关键公式和必要的上下文）

（若论文只是提了一下未具体展开，则写"论文中未具体展开。"然后按一般逻辑补充介绍。对于论文未展开的内容，往往是借鉴/沿用前人的，此时在首次提及时打上来源标签，如 [（xxx, 年份）]。）

## 深入理解

通过在对话中对概念的讨论和澄清，进一步理解：

- 对 xxx 的疑问和澄清：...（将对话中用户提出的困惑和解答有机整合）
- ...

（此节不固定格式，根据实际讨论内容灵活组织：段落、列表、ASCII 图等。）
```

**来源标签**：在概念/组件首次出现于正文时紧跟其后打上标签，不单独成节。

| 标签 | 含义 |
|------|------|
| `[原创]` | 本文作者首次提出 |
| `[引入]` | 已有方法，本文首次引入本领域 |
| `[通用]` | 业界通用/广泛使用的方法 |
| `[（xxx, 年份）]` | 来自前人某篇论文/特定工作 |
| `[不确定]` | 无法从论文判断来源 |

有时是前人的工作后来成为业界通用/广泛使用的方法，则标注为 `[（xxx, 年份）通用]`。

**关键注意点**：
- 写入后告知用户：需在 Better Notes 中 **从 md 文件导入笔记** 并勾选 **保持同步**（仅初次需要）。

## 类型 B：通用笔记

**触发**：讨论内容不依附于具体论文时——话题总结、方法论、工具配置、概念对比等。

**YAML 头**：不含 `parent`/`zoteroKey`，可按需加 `tags` 归类，默认`AI笔记`

```markdown
---
tags: [标签1, 标签2]
model: xx模型
---

笔记标题

> 由 XX模型 于 YYYY-MM-DD 生成

（正文自由组织，无固定模板。根据实际讨论内容灵活安排节结构。示例格式：）

## 背景

...

## 核心内容

...

### 关键要点

- ...
- ...

## 总结与后续

...
```

**标题等级**：`#` H1 标题、`##` H2 节、`###` H3 子节。
