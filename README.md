# my-skills

Personal Claude Code skills, managed via [cc-switch](https://ccswitch.io).

## Structure

```
my-skills/
  ├── code-read-style/             深度学习代码阅读
  ├── make-todoist/                待办管理（Todoist）
  ├── paper-read/                  论文深度阅读 Q&A
  ├── paper-summary/               论文概览
  ├── skill-evolution/             技能进化追踪
  ├── write-zotero-note/           笔记系统（Zotero）
  └── zotero-base-litera-review/   WoS 文献综述
```

## Usage

1. Add this repo to cc-switch as a custom source:
   - Owner: `LitureG`
   - Name: `my-skills`
   - Branch: `main`
   - Subdirectory: *(留空)*
2. Install individual skills from the cc-switch Skills panel.
